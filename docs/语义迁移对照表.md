# mybatis-plus → rbatis-plus 功能语义迁移对照表

基线：baomidou/mybatis-plus **v3.5.17** + mybatis-plus-enhance **2.0.x** + mybatis-3 **3.6.0** + rbatis-wrapper **0.1.1**。

迁移原则：**功能语义对齐，实现方式 Rust 化**。
Java 的 Spring 容器、反射实例化、ThreadLocal 上下文、CopyOnWriteHashMap、
CompletableFuture 分别映射为：显式注册表、trait 对象、Arc 共享上下文、
DashMap、tokio JoinSet。

状态图例：✅ 已迁移并有测试 / 🔶 语义等价但形态不同 / ⬜ 未迁移（路线图）

---

## 目标结构

```
rbatis-plus/                                             Rust 多模块工程（基线 v3.5.17）
├── crates/
│   ├── rbatis-plus-core/                                ★ 核心引擎
│   ├── rbatis-plus-macros/                              ★ 16 注解（过程宏）
│   ├── rbatis-plus-extension/                           ★ 14 InnerInterceptor + 增强能力
│   ├── rbatis-plus-sqlparser/                           ★ sqlparser 适配层
│   ├── rbatis-plus-vernal/                              ★ Vernal + Axum/Actix 集成层
│   └── rbatis-plus-generator/                           ★ 代码生成器（4 模板引擎）
├── src/
│   └── lib.rs                                           facade crate（仅 re-export）
└── docs/
```
